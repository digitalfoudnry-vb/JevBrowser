# Hermes setup

The maintained Hermes instructions are in the [platform setup guide](../jevskills/jev-browser/references/platforms.md#hermes), alongside Claude Code, Codex and OpenClaw.

The canonical skill is `jevskills/jev-browser/`. Use `node scripts/install-skill.mjs --client hermes` to preview installation and add `--apply` to copy it. Then register the local MCP server as described in the guide.
