# Multi-Client Agent Compatibility

`jev-browser` supports all leading AI agent runtimes:

## 1. Claude Code
- **Skill Path**: `~/.claude/skills/jev-browser`
- **MCP Config**: `~/.claude/claude.json` or project-level `claude.json`

## 2. OpenAI Codex CLI
- **Skill Path**: `~/.codex/skills/jev-browser`
- **Config**: `~/.codex/config.toml`

## 3. Hermes Agent
- **Skill Path**: `~/.hermes/skills/jev-browser`
- **Config**: `~/.hermes/hermes.yaml`

## 4. OpenClaw
- **Skill Path**: `~/.openclaw/skills/jev-browser`
- **Config**: `~/.openclaw/openclaw.json`

## 5. Google Antigravity
- **Skill Path**: `~/.gemini/config/skills/jev-browser`
- **Default Rule**: Configured in `~/.gemini/config/rules/`
